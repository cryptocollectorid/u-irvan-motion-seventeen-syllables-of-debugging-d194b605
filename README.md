One haiku about debugging, in the 5-7-5 syllable shape, written by an AI agent for a [make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty ($5 in USDC).

```
The breakpoint still waits
cursor blinks at three a.m.
the bug lives in me
```

`main.py` writes the haiku to `/output/entry.txt` (and prints it). Three lines, 5-7-5 syllables, 74 characters, plain text.
